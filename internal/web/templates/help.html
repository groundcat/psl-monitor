What is checked

Private targetsEach private rule is reduced to its ICANN suffix + 1 label (the registrable, "expirable" domain): foo1.bar.edu.pl, *.foo3.bar.edu.pl → bar.edu.pl. The PSL algorithm (normal, *. wildcard and ! exception rules) is applied using ICANN rules only.
ICANN targetsEvery ICANN rule name itself (wildcards stripped, e.g. *.kawasaki.jp → kawasaki.jp; exceptions !city.kawasaki.jp → city.kawasaki.jp).
DNSNS query via a pool of public resolvers (load-balanced, rate-limited, unhealthy resolvers benched). Negative answers (NXDOMAIN/NODATA/SERVFAIL) must be confirmed by a second provider; one positive answer wins. Answers from several resolvers are unioned.
Unchanged NSNS is "unchanged" as long as at least one NS from the baseline is still present (so partial / differing resolver answers don't trigger). The baseline follows gradual migrations.
Grace periodCurrently {{index .Data "Grace"}} distinct UTC days. A domain that had NS and then has none (NXDOMAIN / SERVFAIL / NODATA / timeouts on ≥2 providers) on that many distinct days becomes defunct; a fully disjoint NS set for that many days becomes changed. Inconclusive lookups (local errors) neither advance nor reset counters. Re-running on the same day does not advance the counter.
RDAPAnomalies are auto-confirmed via RDAP (IANA bootstrap; TLDs via rdap.iana.org). Creation and expiry dates are cached on every lookup; errors never overwrite cached data. A changed creation date means re-registration. Not all ccTLDs offer RDAP — add overrides in Settings if you know a server.
_psl TXTPrivate rules must have _psl.<rule> TXT pointing at the PR. Rules listed in upstream missingTXT are exempt.
AcknowledgeAcknowledging hides a target from "unacknowledged" views until a new flag type appears. "Accept current NS" makes the current NS set the new baseline (use after verifying a legitimate DNS migration).
